网申资料夹隐私政策

更新日期：2026 年 9 月 19 日

网申资料夹用于在招聘网站的申请表单中查找并填入用户自行保存的资料。普通资料在当前 Chrome 浏览器本地处理和保存。本扩展没有开发者运营的账号、同步服务、分析统计或广告服务。

处理哪些数据

  • 用户主动录入的网申资料：例如姓名、联系方式、教育和工作经历、个人评价，以及用户自行添加的其他字段。用户也可以在侧栏粘贴文字创建资料卡。
  • 当前页面的表单线索：用户打开扩展侧栏并选择表单字段时，扩展读取该字段的标签、占位文字、字段名称及附近提示，用于在本地推荐相关资料。扩展不会记录浏览历史。
  • 可选 AI 配置：如果用户自行开启 AI 功能，扩展保存其填写的 HTTPS API 地址、模型名称和开关设置。API 密钥只保存在 Chrome 的会话存储中。

数据如何使用和保存

网申资料保存在 Chrome 的 storage.local 中，用于显示资料侧栏、搜索、字段匹配，以及在用户点击资料卡片后填入网页表单。AI 配置中的地址、模型和开关也保存在本地。API 密钥保存在 storage.session 中，浏览器会话结束后需要重新填写。扩展不会自动提交网申表单。

用户可以在扩展中编辑或删除资料、导出 JSON 备份，并在设置中清除 AI 配置与会话密钥。卸载扩展会清除其 Chrome 本地存储。用户自行导出的备份文件由用户保管；扩展不会自动上传备份。

可选 AI 功能与第三方服务

AI 功能默认不需要启用。用户自行填写兼容的 HTTPS API 地址、模型和密钥，并授权访问相应 API 域名后，扩展才会向该服务商发出请求。扩展不向开发者自有服务器发送这些数据。服务商可能按其自身政策处理和保留请求，用户应在启用前查看所选服务商的隐私政策。

  • 测试连接：发送一条不包含已保存网申资料的测试消息。
  • AI 字段匹配：此开关默认关闭。开启后，侧栏打开且用户切换网页字段时，扩展可能发送当前字段的标签、占位文字、名称及附近提示，以及资料卡的标题、类别和别名。资料卡正文不会用于此请求。字段提示或标题可能包含用户数据，请在启用前确认所选服务商值得信任。
  • AI 长文本压缩：仅在用户选择资料卡并确认发送时，将该卡片的标题、正文和目标字数发送给所选服务商以生成短版。扩展会阻止部分明显包含证件、住址等敏感信息的内容发送，但这种检测不能保证识别所有敏感内容；用户应自行核对后再确认。

这些请求使用 HTTPS，并在请求中向用户指定的服务商发送 API 密钥以完成身份验证。使用服务商 API 可能产生费用。

共享与安全

除上述用户主动配置的 AI 服务商外，扩展不会将资料发送给开发者或其他第三方。扩展不会出售用户数据，也不会将其用于广告。Chrome 本地存储并非由本扩展额外加密；请保护好设备、系统账户、浏览器配置文件和自行导出的备份。

政策变更

如扩展的数据处理方式发生变化，本页面会相应更新，并标明新的更新日期。

适用于 Chrome 扩展程序“网申资料夹”。
