# 网申资料夹

一个面向 Windows Chrome 的本地网申资料助手。点击扩展图标后，它会在当前网页右侧打开资料侧栏。先点击网页输入框，再点击资料卡片，即可把内容填到光标位置。

## 功能

- 识别输入框的标签、占位文字、辅助说明、`name` 和 `id`。
- 自动定位“姓名、手机号、邮箱、学校、专业、学历、毕业时间、个人评价、项目经历、实习经历”等匹配资料。
- 匹配项只会高亮，不会未经确认自动写入。
- 支持普通输入框、多行文本框和基础可编辑区域。
- 侧栏打开后，在任意非输入区域按 `Ctrl+V` 可直接新建资料卡；带“标题：内容”的文本会自动拆分，没有标题时可稍后补填。
- 通过侧栏粘贴创建的内容统一收纳在“粘贴资料”模块中。
- 提供基础信息、教育经历、实习经历、项目经历、校园经历、获奖信息、个人评价、兴趣特长、家庭关系九个默认模块。
- 教育、实习、项目、校园、获奖和家庭模块可以添加多段记录，每段还可以增加自定义字段。
- 选填字段留空时不会保存，也不会出现在侧栏；所有模块打开侧栏时默认收起，便于快速定位。
- 搜索和字段匹配都使用“上一项／下一项”跳转定位，搜索时不会隐藏其他资料，方便连续填写相邻项目。
- 自定义字段支持多行长文本；支持删除旧资料和导出、导入 JSON 备份。
- 可选 AI 长文本压缩：填写自己的 OpenAI 兼容 HTTPS API 和模型，在侧栏选择长资料卡，输入目标字数，确认发送后生成可编辑短版；核对后可填入或另存，不会覆盖原文。
- 可选 AI 字段匹配：在资料管理页开启后，侧栏打开且切换网页字段时调用自己的 API，仅发送字段提示和资料卡标题、类别、别名，不发送资料正文；默认关闭。匹配结果仍需点击卡片才会填入。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹 `job-form-clipboard`。
5. 建议把“网申资料夹”固定到浏览器工具栏。

## 使用

1. 右键扩展图标，打开“选项”，或从侧栏点击“管理资料”。
2. 按模块填写资料；需要多段经历时点击该模块记录下方的“增加”按钮。
3. 打开网申网页并点击扩展图标。
4. 点击网页中的目标输入框。
5. 侧栏会显示识别出的字段并高亮候选资料。
6. 点击资料卡片完成填入。

测试 AI：在“管理资料”顶部展开“AI 设置”，填写服务商提供的 OpenAI 兼容 Chat Completions HTTPS 完整地址、模型名和 API 密钥，然后点击“保存 AI 配置”。浏览器会请求该 API 域名的访问授权。保存后密钥输入框会清空，但当前浏览器会话仍可使用；更换服务商时需填写新密钥。点击“测试 API 连接”会发送一条不含个人资料的测试请求，可能产生少量费用，成功后再测试长文本压缩。建议保持“AI 自动识别当前字段”关闭，优先使用本地字段推荐；如自愿开启 AI 匹配，侧栏打开且切换网页字段时会调用 API。不要把密钥发到聊天里。不是所有大模型原生 API 都采用这一协议，非兼容接口需要单独适配。

长文本压缩只有在点击“修改”后才会发送所选资料。生成稿可继续编辑、复制、填入网页或另存为新卡片，原卡片不会被覆盖。插件会检查字符上限；模型连续返回超长内容时不会展示为可用生成稿。

刷新页面或切换到另一个网站后，需要再次点击扩展图标。这是最小权限设计的一部分。

## 权限与隐私

扩展只申请：

- `activeTab`：你点击扩展后，临时访问当前标签页。
- `scripting`：在当前页面显示侧栏并填入你确认的内容。
- `storage`：将资料保存在 Chrome 本地。

项目没有自建后端、账号、分析统计、剪贴板读取或后台复制监听。普通资料只在本地使用。可选 AI 长文本压缩仅在点击“修改”时发送所选卡片原文；可选 AI 自动匹配默认关闭，开启后仅在侧栏打开且切换网页字段时发送字段提示和资料索引，不发送资料正文。两项功能都使用你配置并授权的 HTTPS API，可能产生服务商费用。API 地址、模型名和开关保存在本地，密钥只保存在当前浏览器会话中，刷新扩展或重启浏览器后需重新输入。资料保存在 `chrome.storage.local`，并未额外加密。本机账户和浏览器配置文件的安全仍由操作系统负责。卸载扩展会清除本地数据，请定期导出 JSON 备份。

Chrome 内部页面、Chrome 应用商店、跨域 iframe、关闭的 Shadow DOM，以及部分特殊富文本编辑器无法可靠填入。遇到不支持的控件时，扩展会尝试复制内容并提示手动粘贴。

## 本地检查

需要 Node.js 18 或更高版本：

```powershell
npm test
npm run check
```

浏览器交互测试需要先在项目目录启动本地静态服务器：

```powershell
python -m http.server 8765 --bind 127.0.0.1
npm run smoke
```

## 仓库隐私约定

仓库只保存扩展源码、测试、示例模板和商店资料，不保存浏览器中的真实网申资料、API 密钥或用户导出的 JSON 备份。`.gitignore` 已排除常见密钥文件、个人资料、简历、备份和生成的扩展压缩包。提交前仍建议运行密钥与个人信息检查。
